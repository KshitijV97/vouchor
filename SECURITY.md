# Security policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** private reporting feature if it is enabled for this repository. This draft has not been published and private vulnerability reporting is not yet configured.

If private reporting is unavailable, first contact a repository maintainer through a private channel listed on the published repository profile. No maintainer email or private contact is configured in this draft; the owner should configure GitHub private vulnerability reporting or publish a monitored security contact before release.

Include affected versions/commit, impact, reproduction steps, and any known mitigations. Avoid sharing personal or sensitive data. Please allow maintainers time to investigate and coordinate a fix before public disclosure.

## Supported versions

No released versions exist yet. The owner will define a support policy before the first release.
