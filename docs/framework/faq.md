# FAQ

## Does CraftRail require a coding agent?

No. It is a repository convention usable by humans. Agent-neutral prompts are optional assistance.

## Does validation prove requirements are correct?

No. It checks selected structure and syntax only. Humans decide whether intent is correct and evidence actually demonstrates behavior.

## Must every change use all lifecycle steps?

No. Scale the process to risk and uncertainty, and preserve the relevant quality gates.

## Can I keep Spec Kit or OpenSpec?

Yes. Choose a single canonical home per artifact and link across tools. See [ecosystem comparison](ecosystem-comparison.md).

## Are all agents tested with this repository?

No. Compatibility is documented from official instruction-file guidance. Direct interactive behavior has not been tested here; see the [matrix](agent-compatibility.md).
