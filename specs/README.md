# Feature specifications

Each numbered directory holds a feature's intent and delivery artifacts. Use `python3 scripts/new_feature.py "Feature title"` to create the next ID. Status `draft` or `proposed` is not approval to implement; the project's human decision owner controls approval.

`000-example-feature/` is illustrative and excluded from the feature-number sequence. Avoid reusing IDs. Keep the spec, plan, tasks, and verification linked as the feature evolves.
