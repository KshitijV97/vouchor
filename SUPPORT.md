# Support

Vouchor is unreleased (design stage). After publication, use GitHub Discussions for questions if enabled and GitHub Issues for reproducible bugs or proposed changes. Security vulnerabilities belong in the private channel described in [SECURITY.md](SECURITY.md), not a public issue.

When asking for help, include the repository revision, operating system and Python version if tooling is involved, exact command/output, relevant artifact paths, and what you expected to happen. Remove credentials and personal data. Questions about behavior should identify the applicable requirement, acceptance criterion, and verification evidence where available.
